What the agent decides

Every search goes to POST /api/workflows/workflow/agentic-product-search/run → the agentic_product_search workflow in Kibana. It grounds an LLM in the live index vocabulary, extracts filters, rewrites the query, routes it, and runs hybrid retrieval + reranking via stored search templates.

  1. 1Ground — prompt carries the index vocabulary
  2. 2Understand — pinned EIS model (structured output)
  3. 3Plan — search-template params
  4. 4Route — products · analytics · help centre
  5. 5Retrieve — BM25 + semantic_text → RRF → Jina rerank
  6. 6Self-correct — relax filters on zero hits
